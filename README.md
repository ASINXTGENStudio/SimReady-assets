# SimReady assets

An optional pack of 72 household 3D objects (kitchen items and room furniture) for the SpineBot simulator.
This repository holds **only the asset pack** - no SpineBot software.

## Download

Get `SpineBot-SimReady-Pack-v1.0.0.zip` from the [v1.0.0 release](https://github.com/ASINXTGENStudio/SimReady-assets/releases/tag/v1.0.0).

- Size: 58,079,852 bytes
- SHA-256: `2a03b88511f5adb1549a1142a35f06a91b439c0d4fce02c2506674ae3efcaf3f`

SpineBot Studio can download and install it from Settings, or use **Add from file...** with the zip.
